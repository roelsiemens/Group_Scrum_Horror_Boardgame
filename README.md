# Still Down Here

## Over het project

Still Down Here is een first-person survival horror game gebaseerd op het bordspel *Dungeon!*.
De speler zit vast in een dungeon en moet genoeg schatten verzamelen om te kunnen ontsnappen. Tijdens het spelen moet de speler monsters ontwijken, sanity beheren en risico’s afwegen.

De game wordt gemaakt in de Unity game engine. 

## Gameplay

De speler verkent verschillende kamers in een donkere dungeon. In kamers kan de speler:

- schatten vinden
- speciale loot (spells) vinden
- een mimic jumpscare tegenkomen
- of helemaal niets vinden

Hoe meer treasure de speler draagt, hoe trager hij beweegt. De speler moet daarom kiezen tussen meer risico nemen of veilig teruggaan.

Wanneer een monster verschijnt, moet de speler vluchten en de line of sight te breken.

De speler ontsnapt door genoeg treasure op een weegschaal te leggen zodat de uitgang opent.

## Features
- First-person movement
- Run gameplay
- Sanity systeem
- Treasure en risk/reward systeem
- Monster AI
- Random loot encounters
- Horror sfeer

## Technologie
- Unity 3D Engine
- C#
